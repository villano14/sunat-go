# sunat-go — milestone 1: signed invoice sent to SUNAT beta

Go library equivalent to Greenter (PHP). Milestone 1 covers Factura 01 with IGV:
model → UBL 2.1 XML → XMLDSig signature → SOAP sendBill → CDR parsing.

## Specs

- S1. Module path `github.com/villano14/sunat-go`, root package `sunat` (user chose "sunat-go (paquete `sunat`)").
- S2. Library architecture, not application architecture: single-responsibility packages
  `model/`, `catalog/`, `ubl/`, `sign/`, `transport/`, `cdr/` (later `gre/`, `validate/`), root `sunat.go` facade
  ("Fachada: Client (equivale al \"See\" de Greenter)").
- S3. Zero dependency on databases, HTTP frameworks or Laravel. The API consumes the library, never the reverse.
- S4. Money uses `shopspring/decimal`, never `float64`.
- S5. Small interfaces for `Signer` and `Transport` so tests never hit SUNAT.
- S6. `context.Context` on every I/O call.
- S7. Typed errors keep the SUNAT code (e.g. 2335, 0151).
- S8. Each package usable on its own (e.g. only `sign` to sign an existing XML).
- S9. Milestone: "Factura 01 con IGV → XML → firma → `sendBill` en beta → CDR aceptado".
- S10. Golden tests: XML generated by Go compared against reference XML (Greenter output when available).
